# Bundled application fonts

These are the same font families used by app/layout.tsx, bundled locally so production builds do not depend on Google Fonts CSS URL formats.

Source: https://github.com/google/fonts/tree/main/ofl (downloaded 2026-11-09).
- plusjakartasans/PlusJakartaSans[wght].ttf
- sora/Sora[wght].ttf
- caveat/Caveat[wght].ttf

Each family retains its adjacent SIL Open Font License file. Font files are unmodified; only their filenames are normalized.
